# MISHA CARDS — коллекция карточек и подарки

Фейковый банк, где деньги заменяются на яркие коллекционные карточки. Каждому игроку выдается уникальный ник (никаких повторов) и стартовая коллекция. Карточки можно переводить другим игрокам — они списываются с одного профиля и зачисляются другому. Все данные хранятся в общей базе, поэтому подарки доходят между разными устройствами и браузерами.

## Как запустить

1. Открой `index.html` в браузере для локальной проверки.
2. Загрузи файлы проекта в репозиторий GitHub.
3. В репозитории открой **Settings → Pages**, выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. После публикации сайт появится по адресу `https://<твой-ник>.github.io/<название-репозитория>/`.

## Возможности

- 🪪 Регистрация с уникальным ником и входом по ПИН-коду.
- 💳 Стартовый набор карт и лимиты выпуска по каждому номиналу.
- 🔁 Перевод выбранных карточек по нику: карты списываются у отправителя и зачисляются получателю.
- 🧪 Ежедневный дроп — новые карточки каждые 24 часа.
- 📊 Таблица лидеров и история операций.
- 📤 Экспорт/импорт JSON для резервной копии.

## Важное ограничение

GitHub Pages не предоставляет сервер или общую базу данных. Сейчас профили и переводы работают благодаря бесплатному облачному хранилищу **textdb.online** — запись и чтение происходят напрямую из браузера, CORS открыт для всех гитхаб-страниц. Это значит, что:

- Данные видны всем игрокам, зарегистрированным на этом сайте.
- Подарки доходят между разными устройствами и браузерами.
- Никакой регистрации или ключей не требуется — просто открывай сайт и играй.

Если общая база временно недоступна (проблемы с сетью), игра автоматически переходит в локальный режим: данные хранятся только в этом браузере на этом устройстве.

## Технические детали

- Используется чистый HTML/CSS/JS без сторонних фреймворков.
- Карточки имеют rarity (редкость) и номиналы в игровой валюте «искры».
- Хранилище: `textdb.online` — POST-форма без регистрации, CORS `*`, без ограничений на количество запросов в рамках бесплатного тарифа.
- Адаптивный дизайн, мобильный-first, pinch-zoom отключен для удобства управления.

## Разработка

- `node --check js/app.js js/store.js js/cards.js` — проверка синтаксиса.
- `check_preview` — автоматическая проверка на JS-ошибки при загрузке страницы.
- Добавляй новые карточки в `js/cards.js`, новые функции — в `js/store.js` и `js/app.js`.
