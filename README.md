# MISHA BANK 🏦

Фейковый банк с **лимитированными картами-деньгами**: уникальные ники, кошелёк из карт разных номиналов, переводы карт другим клиентам и ограниченная эмиссия.

> Это игра. Никаких настоящих денег, платежей и персональных данных — только картинки карт и цифры в браузере.

## Как запустить локально

Просто открой `index.html` в браузере — сервер не нужен.

Если хочешь как на Pages: `npx serve .` или любой статический сервер.

## Как бесплатно выложить на GitHub Pages

1. Создай репозиторий на GitHub (например `misha-bank`), лучше **публичный**.
2. Залей файлы проекта в ветку `main`:
   ```bash
   git init
   git add .
   git commit -m "MISHA BANK"
   git branch -M main
   git remote add origin https://github.com/<твой-ник>/misha-bank.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment**.
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://<твой-ник>.github.io/misha-bank/`

Файл `.nojekyll` уже лежит в корне — он отключает обработку Jekyll, чтобы всё отдавалось как есть.

## Правила банка

- **Ник уникален**: 3–16 символов, латиница, цифры, `_`. Повторить ник нельзя — банк помнит всех клиентов.
- **ПИН-код** 4–6 цифр — вход в свой счёт.
- **Стартовый набор**: 2×50, 2×100, 1×250, 1×500 ₽ при регистрации (пока в тираже есть карты).
- **Лимиты эмиссии**: 50 ₽ — 120 шт, 100 ₽ — 100, 250 ₽ — 80, 500 ₽ — 55, 1000 ₽ — 30, 5000 ₽ — 10.
  Когда тираж кончился, новые карты этого номинала не выпускаются.
- **Перевод**: вписываешь ник получателя, выбираешь карты и количество → карты уходят из твоего кошелька и появляются у него. Комиссии нет.
- **Демо-клиенты** (вкладка «Банк») — чтобы было кому переводить.
- **Бэкап**: выгрузка/загрузка JSON во вкладке «Банк».

## Важно про GitHub Pages

GitHub Pages — это **статический хостинг**, у него нет базы данных. Поэтому:

- Все профили живут в `localStorage` **одного браузера** — на одном устройстве регистрация, вход и переводы работают по-настоящему: баланс получателя реально растёт.
- На **другом устройстве** будет свой отдельный банк: там не будет твоих ников и переводы между устройствами не пройдут.

Если нужны реальные переводы между разными людьми на разных телефонах, нужен общий бэкенд. Бесплатные варианты: Supabase (Postgres + REST, бесплатный тариф) или Firebase Realtime Database. Тогда `js/store.js` заменяется на запросы к этой базе, а интерфейс остаётся тем же.

## Структура

```
index.html      — разметка: вход, кошелёк, перевод, банк
css/styles.css  — тёмная тема, карты, адаптив под телефон
js/cards.js     — номиналы карт и лимиты эмиссии
js/store.js     — профили, уникальность ников, тиражи, переводы, бэкап
js/app.js       — интерфейс и обработка событий
```
